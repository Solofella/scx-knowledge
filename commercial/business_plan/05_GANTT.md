1. ✅ Pipeline stabilization — 3 consecutive 25-record clean runs
2. ✅ Landing page live (subtextcx.com EN + ES)
3. ✅ Weekly Brief template designed (Deliverable 2)
4. ✅ Pitch deck pricing fix
5. ✅ Value prop locked
6. ✅ Demo script finalized
7. ✅ Pilot contract template ready

**Any blocker in this list = delay Pilot 1 outreach**

### Must-Complete Before Pilot 2+3 Outreach

2. ✅ Testimonial secured
3. ✅ Manager Action Summary template designed (Deliverable 3)

## Dependencies Map

### Landing Page → Outreach

**Cannot start warm network outreach until landing page is live.**

Every prospect will Google "SubtextCX" — the landing page must exist before first contact.

**Dependency:** Landing Page W22 → Pilot 1 Outreach W18–21 (can start conversations, but cannot send to landing page until W22)

---

### Stabilization Gate → Pilot 1 Signed

**Cannot sign Pilot 1 contract until stabilization gate passes.**

No client delivery before 3 consecutive 25-record clean runs.

**Dependency:** Stabilization W17 → Pilot 1 Signed W23

---

### Pilot 1 Case Study → Pilot 2+3 Outreach

**Pilot 2+3 outreach is more effective with Pilot 1 case study.**

Can start outreach without it, but conversion rate will be lower.

**Dependency:** Case Study W32–33 → Pilot 2+3 Outreach W27–35 (overlap acceptable, ideal to have case study by W32)

---

### Spanish Pipeline → Hispanic Operator Outreach

**Cannot effectively target Spanish-speaking operators until Spanish pipeline capability is validated.**

English-only pipeline can process Spanish reviews but quality is unknown.

**Dependency:** Spanish Validation W24–26 → Hispanic Outreach W31–35

---

## Risk Mitigation

### Risk 1: Stabilization Gate Delay

**Risk:** Pipeline fails 3-clean-run test in W17.

**Impact:** Delays Pilot 1 by 2–4 weeks.

**Mitigation:**
- Start stabilization testing early (W16)
- Run 5+ test batches before "official" gate attempt
- Identify failure patterns early

---

### Risk 2: Landing Page Delay

**Risk:** Platform choice, design, or content delays landing page past W22.

**Impact:** Cannot start outbound outreach, delays Pilot 1 signed.

**Mitigation:**
- Lock platform decision by W18 (no analysis paralysis)
- Use Webflow template (fast deployment)
- Content draft ready by W19 (parallel with design)

---

### Risk 3: Pilot 1 Doesn't Convert

**Risk:** Pilot 1 completes 30 days but doesn't convert to paid client.

**Impact:** No case study, weaker Pilot 2+3 outreach, MRR target at risk.

**Mitigation:**
- Qualify Pilot 1 carefully (budget authority confirmed)
- Weekly feedback calls (surface objections early)
- Offer discount on first 3 months if converting (e.g., $1,200/mo vs. $1,500/mo)

---

### Risk 4: Spanish Pipeline Delays

**Risk:** ESS/HSI Spanish vocabulary extension takes longer than planned.

**Impact:** Cannot target Hispanic operators in Q3.

**Mitigation:**
- Parallel track: English outreach proceeds regardless
- Hispanic outreach is additive, not critical path
- Defer to Q4 if necessary (English market sufficient for M4 gate)
